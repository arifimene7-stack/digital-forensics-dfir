# Day 3 — Digital Evidence Acquisition Strategy

## Objective
Understand the main digital evidence acquisition methods
and select an appropriate method based on the investigation.

## Acquisition Methods
1. Logical Acquisition
2. Physical Acquisition
3. Live Response

## Scope
This is an educational exercise based on a synthetic
investigation scenario. No real system disk will be acquired.

## Expected Deliverables
- Acquisition methods comparison.
- Decision matrix.
- Acquisition plan.

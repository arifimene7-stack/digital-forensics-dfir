# Blind Case — DFIR-2026-002

## Scenario
A workstation generated an alert related to an unfamiliar
scheduled task.

## Objective
Determine whether the available evidence supports suspicious
activity, benign administration, or an inconclusive assessment.

## Evidence
All evidence is synthetic and created for this laboratory exercise.

## Rules
- Preserve original evidence.
- Record hashes.
- Separate observations from interpretations.
- Do not assume that an alert proves compromise.
- Document limitations and alternative explanations.
